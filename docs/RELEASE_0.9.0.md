# HongguoTV v0.9.0 (Kotlin TV 原生版)

本版本為紅果 TV 原生 Android TV / 車用安卓機版本，支援遙控器焦點導航與觸控操作，已於實機測試通過。

## 主要更新功能

1. **全集解鎖與播放**：整合預載入 API 與 CENC 解密，支援全劇集直接流暢播放。
2. **ExoPlayer 原生無縫換集（Gapless Playback）**：
   - 影片起播後自動於背景預解析下一集串流並注入 ExoPlayer 播放佇列。
   - 前集播畢或切換時，底層解碼管線直接渲染下一集首幀（切集耗時僅約 110ms），無轉圈等待。
   - 支援於「設定 $\to$ 播放偏好」或播放畫面按遙控器「上鍵 $\to$ 播放設置」開啟或關閉無縫換集。
3. **穩定度與記憶體優化**：
   - 佇列嚴格維持最多 2 個實例，切換時即刻釋放舊集數資源，杜絕低配電視端 OOM 風險。
   - 修復換集時串流資源所有權移交，避免下一集播放中途誤關連線。
4. **Downloader 一鍵安裝支援**：
   - 提供專屬 APK 固定下載鏈結，方便透過電視端 Downloader 數字短碼快速安裝。
