# 宏果tv v0.9.07

## 更新重點

- **全新「皇家午夜藍＋流金霓虹青 3D 影院電視」App Icon 與 Android TV 桌面橫幅**：徹底擺脫舊版紅果實構圖，提升電視桌面與左上角品牌標誌辨識度。
- **更新入口收斂於「設置」首位與啟動單次檢查**：
  - 將「检查更新 · 当前版本 v0.9.07」置於「设置」頁面右側欄第一排首位（在頂部導覽列停在「设置」按 `↓` 即可直接點擊檢查）。
  - 每次啟動軟體時僅自動檢查一次，若發現新版會主動彈窗提醒使用者決定是否下載安裝（不再每 15 秒頻繁輪詢或背景偷跑下載）。
- **播放中遙控器 `↑` / `↓` 跨季快速跳轉**：
  - 播放中按遙控器 `↑`（頂部控制列）新增「选季（共 X 季）」按鈕，可直接切換同系列各季。
  - 播放中按遙控器 `↓`（右側選集面板）於集數上方直接提供 4 欄網格「同系列选季」按鈕。
- **多季劇集完整探索與多列網格選取**：解決 10 季以上劇集漏季與單列超出電視畫面無法選取的問題。
- **直式（9:16）與橫式（16:9）標籤精準修正**：跨頁保留 API 畫面方向並讀取首集串流真實解析度。
