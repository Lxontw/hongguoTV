# 宏果tv v0.9.08

## 更新重點

- **修復 ByteVC2 編碼分集無法播放與重試迴圈**：
  - 當內聯播放清單僅提供電視硬體不支援的 `bytevc2` 編碼時，自動將備援接口（`fallback_api`）的 `codec_type` 改寫為 `3`（標準 HEVC / `bytevc1`）與 `1`（AVC）重新取源，直接取得電視可硬解秒播的 MP4 串流。
- **匿名設備 Token 空回應即時刷新**：
  - 針對上游播放接口單次有效匿名設備 Token 機制，當首次收到空回應時立即刷新設備註冊並重試，同時替換已失效的備援域名，消除切集時的冗餘等待。
- **防禦性串流校驗與編碼優先序優化**：
  - 內聯清單若缺少 `spade_a` 解密金鑰則自動退回備援接口；核對備援串流之 `video_id` 與時長一致性；同解析度下優先選擇 `H.264` 其次 `HEVC`。
- **持久化設備註冊 Cookie 與錯誤分類優化**：
  - 跨啟動保留設備註冊 Cookie，並避免對非暫時性解碼錯誤進行無意義的自動重試迴圈。
