# 宏果tv v0.9.09 更新说明

## 新增与优化
1. **题材分类筛选与「今日上新」**：接入 App 原生分类接口，在首页提供「全部推荐」「今日上新」及多元题材快速筛选胶囊按钮，并自动识别「今日上新」角标。
2. **海报图片防破图标准化**：自动拦截私密 `.heic` 签名缩略图并转换为公开 CDN 640px 标准 JPEG，彻底解决 Android TV 无法解码 HEIC 封面及链接过期破图问题。
3. **播放器时间轴弹幕开关与重复合并**：在播放控制列与设置中新增「弹幕：关 / 开」（默认关闭），支持顶部 3 轨道轻量渲染与重复弹幕 `× N` 金色胶囊合并展示。
4. **多片源平台架构（红果 / 稀饭 / 河马）**：支持在首页/搜索顶栏及设置中一键切换「红果」「稀饭」「河马」三大片源平台，收藏与观看历史通过命名空间隔离并向下兼容。
