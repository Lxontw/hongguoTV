# 紅果短劇 TV v0.9.11 更新說明

## 播放穩定度與連線升級

1. **修復劇集無法播放與載入失敗的問題**：
   - 配合官方今日最新的連線驗證調整，全面升級了播放器的連線機制，解決點選劇集後無法觀看或一直顯示暫不可用的狀況。
2. **加快點選劇集後的開播速度**：
   - 調整了影片路線的優先順序，現在點開劇集會直接走最新、最順暢的主線路，減少等待轉圈的時間。

   - 萬一遇到尖峰時段主線路忙碌，系統會自動重新連線並切換至備用路線，同時避免重複無效的重試，讓追劇過程更穩定順暢。
