# 紅果短劇 TV v0.9.12-rc1 測試版

## 自由選擇想看的片源

現在可以到「設定 → 片源開關管理」，選擇首頁要顯示哪些平台。關閉目前使用的來源時，會自動回到紅果，原有收藏與觀看記錄都會保留。

紅果固定開啟，西飯與河馬預設開啟。新增的 ReelShort、DramaBox 海外片源預設關閉，有需要時再自行開啟即可。片源開關也會隨備份與設定還原保存。

## 新增海外公開試看內容

兩個海外平台提供英文片單、搜尋與公開試看集數。遇到需要付費或確認觀看權限的集數，會顯示提示，請到官方平台確認。不同地區與網路環境可觀看的內容可能有所差異。

## 彈幕換集更穩定

連續觀看、無縫換到下一集時，會更新為該集的彈幕，並避免上一集較晚載入的內容混進來。彈幕仍依原本的影片時間出現，不會把一般評論當成替代彈幕；沒有彈幕的集數就保持清爽畫面。

## 測試版安裝提醒

本版已通過 122 項程式測試、安裝包編譯與公開片源連線抽查，尚待電視實機確認遙控器操作與連播畫面。這次先提供手動下載安裝，不推送正式自動更新。

請下載本頁附加的 APK 安裝，保留原 App 即可覆蓋更新，避免解除安裝造成本機記錄遺失。
