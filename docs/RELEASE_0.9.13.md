# 紅果短劇 TV v0.9.13 更新說明

## 搜尋更聰明，想看的劇不再找不到

1. **大幅改善搜尋準確度**：
   - 修復了先前輸入劇名卻常常找不到影片的問題。現在不管是搜尋熱門短劇、動漫劇集，或是最近剛上架的新劇，都能更快、更完整地找到想看的內容。
2. **劇名輸入更彈性**：
   - 搜尋時就算漏打標點符號、只記得劇名前半段，或是用繁體字輸入，系統都會自動幫您比對並把最符合的劇集排在最前面。

## 喜番與河馬片源修復，找片更方便

1. **恢復喜番與河馬劇集載入**：
   - 配合平台最新調整，修復了喜番與河馬片源無法瀏覽與搜尋的狀況。
2. **河馬首頁新增分類篩選**：
   - 切換到河馬片源時，現在也能在首頁上方直接挑選喜愛的題材分類，找劇更順手。

## 播放與連線更穩定

1. **自動切換備用播放路線**：
   - 觀看過程中若遇到單一路線忙碌或網路波動，播放器會自動切換到其他順暢的備用路線，減少卡頓與載入失敗。
2. **劇集介紹頁面雙重備援**：
   - 點進劇集時若遇到主路線回應較慢，會自動改走備用路線載入集數清單，讓追劇體驗更穩定。

## 電視直接更新

- 在電視版的「設定 → 版本與更新」選擇檢查更新，即可下載並安裝新版。原有收藏、觀看進度與設定都會完整保留，不需要先解除安裝。
