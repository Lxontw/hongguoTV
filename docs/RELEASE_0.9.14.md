# 紅果短劇 TV v0.9.14 更新說明

## 修復影片無法播放與重試失敗問題

1. **全面恢復劇集載入與播放**：
   - 配合平台最新調整，全面升級了播放連線與驗證機制，解決點選劇集後顯示「暫不可用」及自動重試三次仍無法開始播放的狀況。
2. **提升電視端畫質相容性**：
   - 主動優先向平台請求適合電視硬體解碼的順暢畫質，並改善切換 1080P、720P 等不同解析度時的載入穩定度，讓每一集都能順利開播。

## 搜尋與多片源整合（包含近期更新內容）

1. **搜尋更聰明完整**：
   - 修好了輸入劇名找不到影片的問題，無論是熱門短劇、動漫劇集或最新上架劇名，就算漏打標點或用繁體字搜尋也能更快排在前面找到。
2. **喜番與河馬片源同步修復**：
   - 恢復喜番與河馬的瀏覽及搜尋功能，河馬首頁也加入了題材分類篩選。
3. **播放路線自動備援**：
   - 遇到單一線路忙碌時會自動切換備用路線，點開劇集介紹頁也會自動改走備援路徑，追劇過程更穩定順暢。

## 電視直接更新

- 在電視版的「設定 → 版本與更新」選擇檢查更新，即可下載並安裝新版。原有收藏、觀看進度與設定都會完整保留，不需要先解除安裝。
