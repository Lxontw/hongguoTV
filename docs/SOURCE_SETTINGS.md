# 片源開關與彈幕調整

在「設定 → 片源開關管理」可以選擇首頁要顯示哪些來源。紅果固定開啟；西飯、河馬預設開啟；ReelShort、DramaBox 預設關閉。選取來源後按確認即可切換開關，按返回離開。

關閉目前使用的來源時，預設片源會回到紅果。開關會保留在這台電視，也會隨「備份與恢復」保存；恢復時需選擇還原設定。收藏與觀看記錄仍保留，開關只管理片源選單。

兩個海外來源提供英文片單與官方公開試看集數。需付費或確認觀看權限的集數會顯示提示；ReelShort 支援公開影片與串流，DramaBox 支援公開的未加密影片，其他格式會顯示提示。部分網路或地區可能無法連線。

彈幕仍只顯示原本的時間軸彈幕，不會拿一般評論補位。無縫換集會載入新一集資料，並忽略上一集較晚回來的結果。沒有彈幕的集數，以及未提供彈幕的外部來源，畫面不會出現替代留言。
